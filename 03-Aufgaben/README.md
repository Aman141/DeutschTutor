# 03 · Aufgaben

Benennung: `A-NNN-Thema.md` — die Nummer passt zur Lektion, aus der sie stammt.

**Wichtig: Abgabe und Korrektur stehen in derselben Datei.** Ich schreibe unter
`## Meine Abgabe`, Frau Ritter füllt darunter `## Korrektur`. So sieht man später
beides nebeneinander.

```markdown
---
aufgabe: A-NNN
lektion: L-NNN
gestellt: JJJJ-MM-TT
abgegeben:
status: offen        # offen | abgegeben | korrigiert
---
# A-NNN · Thema
## Aufgabe
## Hilfen              <!-- Redemittel, Wortschatz -->
## Meine Abgabe
## Korrektur
```

Offene Aufgaben werden bei `/review` aufgelistet. Nichts verschwindet still.
