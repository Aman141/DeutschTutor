# 04 · Prüfungen

Benennung: `P-NNN-JJJJ-MM-TT-Typ.md`

Ziel: **telc Deutsch B1 (Zertifikat Deutsch)**. Bestehensgrenze **60 %**, schriftlicher
und mündlicher Teil werden getrennt gewertet.

| Prüfungsteil | Aufgaben | Zeit | Gewicht |
|---|---|---|---|
| Leseverstehen + Sprachbausteine | 3 + 2 Teile | 90 Min (mit Schreiben) | |
| Hörverstehen | 3 Teile, Teil 1 und 3 nur **einmal** | 30 Min | |
| Schriftlicher Ausdruck | 1 Brief, 3 Leitpunkte | 30 Min | |
| Mündlicher Ausdruck | 3 Teile | ~15 Min | separat |

Modelltest im Elternordner: `../telc_deutsch_b1_zd_uebungstest_1.pdf` — dient als
Muster für Format und Schwierigkeit. Aufgaben werden neu gebaut, nicht kopiert,
damit der echte Modelltest für die Generalprobe (M17) unverbraucht bleibt.

Erzeugt von `/exam`. Ergebnisse laufen in die Prüfungstabelle in
[[fortschritt.md]].
