# Meine Aufnahmen

Hier lege ich eigene Sprachaufnahmen ab. Frau Ritter hört sie an und korrigiert
Aussprache, Betonung und Flüssigkeit — Fehler wandern mit `#aussprache` ins
[[fehlerlog]].

Benennung: `JJJJ-MM-TT-Thema.wav` (oder `.m4a` — beides geht).

Gut geeignet: die Sätze aus der letzten Lektion nachsprechen, eine Aufgabe laut
vorlesen, eine Minute frei über ein Thema sprechen.
